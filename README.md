# Bad Decisions

Three two-player drinking card games in one file. Open `index.html` on a phone and pass it back and forth. No install, no dependencies.

- **Cursed 21**: blackjack with no dealer, a random target number and curse each round, hidden hands, bluff-bragging, spying and Five-Card Charlies.
- **Night Bus**: Ride the Bus with tolls, checkpoints, a roadside event and a Driver who can hex or curveball you.
- **Rule Stack**: every rank is a challenge, every King adds a permanent rule, every 7th card is a Chaos Event, the 4th King is Last Call.

Pick **Chill** or **Spicy 18+** on the home screen. Spicy needs both players to tick a consent box, and every dare can be skipped (the chicken costs 3 sips). Tap a player chip during play to add a sip to their tally.
